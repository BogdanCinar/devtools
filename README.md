# DevTools Platform

Essential developer tools, fast, no bullshit. Free, privacy-first, and works offline.

## Live Demo

🔗 **https://toolbox-alpha-red.vercel.app**

## Tools

- **JSON Formatter** - Format, validate, and beautify JSON
- **JWT Decoder** - Decode and inspect JWT tokens
- **Base64** - Encode/decode Base64 strings and files

## Features

- 🌙 Dark/Light mode
- 🔒 Privacy-first (all processing client-side)
- 📱 Responsive design
- ⚡ Fast (Next.js + Turbopack)

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```
